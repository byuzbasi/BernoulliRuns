# Print an Exact Run-Count Tail Result

Print an Exact Run-Count Tail Result

## Usage

``` r
# S3 method for class 'runs_exact_tail'
print(x, digits = max(3L, getOption("digits") - 3L), ...)
```

## Arguments

- x:

  An object returned by
  [`runs_tail()`](https://byuzbasi.github.io/BernoulliRuns/reference/runs_tail.md).

- digits:

  The number of significant digits used for displayed values.

- ...:

  Additional arguments reserved for future methods.

## Value

`x`, invisibly.
